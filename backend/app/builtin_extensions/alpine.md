当需要轻量级交互逻辑时：
- 使用 Alpine.js CDN：<script defer src="https://cdn.jsdelivr.net/npm/alpinejs@3.x.x/dist/cdn.min.js"></script>
- 使用 x-data 定义组件状态
- 使用 x-show/x-if 控制显隐
- 使用 x-on:click 等绑定事件
- 使用 x-model 双向绑定表单
- 使用 x-for 循环渲染列表
- Alpine.js 适合简单交互，不需要复杂状态管理的场景
